# WiFi Heatmap website

Static site for GitHub Pages. No build step.

## Publishing

1. Push this `website/` directory to a repo.
2. Settings -> Pages -> Source: deploy from branch, folder `/website`.
3. URLs become:
   - Privacy: `https://<user>.github.io/<repo>/privacy.html`
   - Terms: `https://<user>.github.io/<repo>/terms.html`
   - Support: `https://<user>.github.io/<repo>/support.html`

## Before publishing

Replace `kalitaventures@gmail.com` throughout with a real address, and update the
same placeholder in the app (PaywallView, SettingsView, ShareSheet).
